Web panel: `entrypoint install --panel-name panel.example.com` serves it through Caddy with an automatic certificate and prints the first administrator password once (change it with `entrypoint panel password`). From the panel you create an app with its hosts in one step and get its connection bundle with ready commands for a Linux machine, the Node.js SDK or Docker Compose; manage routes, tokens and VPN machines; issue VPN keys; and check DNS records and revisions. Sessions use an HttpOnly, Secure, SameSite=Strict cookie, changes need a CSRF token and the panel's Origin, and failed logins are limited per IP address.

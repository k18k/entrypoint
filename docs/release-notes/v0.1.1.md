Poprawka nazewnictwa w SDK.

## Zmiany

- Adapter `@k18k/entrypoint/http`: `expose(handler, opts)` zamiast `connectTo(handler, opts)`. `connectTo` i typ `ConnectOptions` zostają jako przestarzałe aliasy, więc kod napisany pod 0.1.0 działa bez zmian.

```js
import { expose } from "@k18k/entrypoint/http";

await expose(app, { service: "api", healthCheck: "/health" });
```

## Instalacja

```bash
curl -fsSL https://raw.githubusercontent.com/k18k/entrypoint/master/scripts/install.sh | sudo sh
npm install github:k18k/entrypoint-ts#v0.1.1
```

Obraz konektora: `ghcr.io/k18k/entrypoint-connector:0.1.1`. Brama i konektor bez zmian funkcjonalnych względem 0.1.0.
